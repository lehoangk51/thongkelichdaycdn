Chọn file lịch giảng dạy Excel của trường. File chỉ được đọc ngay trên máy của bạn, không tải lên đâu cả.

Bấm để chọn một hoặc nhiều file Excel
hoặc kéo thả nhiều file .xlsx vào đây. Có thể thêm file tiếp nhiều lần.

Nếu hai file có cùng tên sheet (ví dụ bản gốc và bản điều chỉnh của cùng một tháng), trang dùng file được lưu sau cùng. Sheet đang ẩn trong Excel được bỏ qua.

Chưa có dữ liệu. Hãy chọn file lịch giảng dạy.
