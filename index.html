    TKB của Giáo viên

    Số tiết, ngày lên lớp và số buổi của từng giáo viên theo tháng.

    Chưa có dữ liệuMở mục để nạp file Excel.

    Thời khóa biểu lớp

    Chọn lớp và tháng để xem ngày nào có buổi nào, học tiết nào.

    Hồ sơ công tác phí

    Giấy đề nghị thanh toán, bảng kê và bản xác nhận cho các buổi dạy ở trung tâm liên kết. Chọn Giáo viên và chọn tháng ở ô lọc phía trên.

    Chưa có buổi dạy phù hợpChọn một giáo viên có buổi dạy tại trung tâm liên kết ở ô lọc phía trên.

    Dữ liệu lịch

    Trang tự nạp các file Excel trong thư mục data/ của kho GitHub. Bạn cũng có thể chọn file từ máy, file chỉ được đọc trên máy của bạn, không tải lên đâu cả.


    Bấm để chọn một hoặc nhiều file Excel
    hoặc kéo thả file .xlsx vào đây. Có thể thêm file nhiều lần.

    Nếu hai file có cùng tên sheet (ví dụ bản gốc và bản điều chỉnh của cùng một tháng), trang dùng file được lưu sau cùng. Sheet đang ẩn trong Excel được bỏ qua.
